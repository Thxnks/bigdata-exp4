# 角色 D：前端展示页面

把后端 `GET /api/stat/list` 返回的统计结果，渲染成**汇总卡片 + 柱状图 + 折线图 + 明细表**。

## 文件

```
frontend/
├── index.html        # 页面(单文件, 含样式和脚本)
├── echarts.min.js    # 图表库(本地, 离线可用)
└── README.md
```

## 怎么打开（零部署）

1. 确认后端在运行：浏览器能打开 `http://192.168.88.101:8080/api/stat/list` 看到 JSON
2. **直接双击 `index.html`** 用浏览器打开即可（后端 CORS 已放行 `*`，`file://` 也能取数据）
3. 页面顶部「接口地址」默认指向 `192.168.88.101:8080`，换集群/IP 时改这里就行（会自动记住）

## 功能

- **汇总卡片**：统计条数、预订成功总量、航空公司数、时间段数
- **柱状图**：各航空公司预订成功总量（Top 15，降序）
- **折线图**：各时间段预订成功量趋势
- **明细表**：全部数据，点表头可按时间/航司/成功数排序
- **自动刷新(5s)**：勾上后实时刷新——配合 Spark 流式处理，可演示"producer 灌数据 → 页面数字实时增长"，很出效果
