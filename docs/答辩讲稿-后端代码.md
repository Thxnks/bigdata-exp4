# 答辩讲稿 · 后端代码逐文件讲解（角色 C）

> 后端是标准 Spring Boot 项目，共 8 个文件。按"一个请求怎么流过去"的顺序讲，每个文件标了**答辩要点**。

## 一个请求的完整链路（先记住全貌）

```
前端 fetch GET /api/stat/list
  → CorsConfig 放行跨域
  → StatController.list()
  → StatResultRepository.findAll()   (JPA 自动生成 SQL)
  → 查 MySQL stat_result 表
  → 结果(List<StatResult>) 自动转 JSON 返回前端
```

职责分层：**配置 → 启动 → 实体 → 仓库 → 控制器 → 跨域**。

---

## 1. `sql/init.sql` — 数据库建表（存储层根基）

```sql
CREATE DATABASE IF NOT EXISTS bigdata_exp4 ...;
CREATE TABLE stat_result (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,         -- 自增主键
    stat_hour VARCHAR(50),                         -- 时间段
    airline_code VARCHAR(20),                      -- 航司
    success_count INT,                             -- 成功数
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP -- 写入时间(自动)
);
```

**要点**：这是我设计的存储结构。三个核心字段对应统计目标；`id` 自增主键；`created_at` 由数据库自动填当前时间。

## 2. `backend/pom.xml` — 项目依赖

关键三个依赖：
- `spring-boot-starter-web`：提供 Web/REST 能力（写接口）
- `spring-boot-starter-data-jpa`：JPA + Hibernate，**不用手写 SQL** 就能操作数据库
- `mysql-connector-j`：MySQL 驱动

**要点**：Spring Boot 3.2.5 + JDK17；用 starter 一站式引入依赖，省去大量配置。

## 3. `application.properties` — 配置

```properties
server.port=8080
server.address=0.0.0.0                  # 监听所有网卡，别的机器也能访问
spring.datasource.url=jdbc:mysql://localhost:3306/bigdata_exp4?...
spring.datasource.username=root
spring.datasource.password=root
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.jpa.hibernate.ddl-auto=validate  # 启动时只"校验"表结构，不自动改表
```

**要点**：
- `0.0.0.0` → 前端从别的机器也能连这个接口
- `ddl-auto=validate` → 启动时校验实体类和 `stat_result` 表是否对得上，**不乱改表**（比 `update`/`create` 安全）
- URL 里 `serverTimezone`/`allowPublicKeyRetrieval` 是连 MySQL 8 的常见必要参数

## 5. `StatResult.java` — 实体类（Java 对象 ↔ 数据库表）

```java
@Entity
@Table(name = "stat_result")                       // 类映射到 stat_result 表
public class StatResult {
    @Id @GeneratedValue(strategy = IDENTITY)        // 主键，对应自增 id
    private Long id;
    @Column(name = "stat_hour", length = 50)        // 字段映射到列
    private String statHour;
    @Column(name = "airline_code", length = 20)
    private String airlineCode;
    @Column(name = "success_count")
    private Integer successCount;
    @Column(name = "created_at", insertable=false, updatable=false) // 只读，DB 自动填
    private LocalDateTime createdAt;
    // getter/setter...
}
```

**要点**：
- `@Entity`+`@Table` → 这个类代表 `stat_result` 表，**一个对象 = 一行数据**
- `@Column(name=...)` → Java 驼峰 `statHour` 映射到下划线列名 `stat_hour`
- `created_at` 标 `insertable=false, updatable=false` → JPA 不写它，交给数据库自动填时间
- getter/setter → 序列化成 JSON 时靠它们取值（JSON 里字段是 `statHour` 这种驼峰）

## 6. `StatResultRepository.java` — 数据访问层

```java
@Repository
public interface StatResultRepository extends JpaRepository<StatResult, Long> {
}
```

**要点（常被问）**：空接口却自动拥有整套增删改查。继承 `JpaRepository<实体类型, 主键类型>` 就白送 `findAll()`/`findById()`/`save()`/`count()` 等方法，**底层 Hibernate 自动生成 SQL**，一行 SQL 都不用写。

---

## 7. `StatController.java` — 接口层

```java
@RestController
@RequestMapping("/api/stat")                  // 类下接口都以 /api/stat 开头
public class StatController {
    private final StatResultRepository repository;
    public StatController(StatResultRepository repository) {   // 构造器注入
        this.repository = repository;
    }
    @GetMapping("/list")                       // 完整路径 = /api/stat/list
    public List<StatResult> list() {
        return repository.findAll();           // 查全表，自动转 JSON
    }
}
```

**要点**：
- `@RestController` → 方法返回值**自动序列化成 JSON**
- `@RequestMapping("/api/stat")` + `@GetMapping("/list")` 拼成 `GET /api/stat/list`
- 构造器注入 repository（Spring 自动注入实例）
- `findAll()` 查出所有统计 → 返回 `List<StatResult>` → 前端拿到 JSON 数组

## 8. `CorsConfig.java` — 跨域配置

```java
@Configuration
public class CorsConfig {
    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {
            @Override public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/api/**")   // 对 /api 下所有接口
                        .allowedOrigins("*")      // 放行任意来源
                        .allowedMethods("GET");   // 只允许 GET
            }
        };
    }
}
```

**要点**：前端是独立页面、和后端不同源，浏览器默认拦跨域请求。这里放行 `/api/**` 的跨域 GET，前端 `fetch` 才能正常拿数据。

## 高频追问速答

- **Repository 空接口怎么就能查？** 继承 Spring Data JPA 的 `JpaRepository`，框架在运行时自动实现增删改查，底层 Hibernate 生成 SQL。
- **`ddl-auto=validate` 是什么？** 启动时只校验实体和表结构一致，不自动改表，安全。
- **JSON 字段为什么是 statHour 驼峰？** 实体字段是 `statHour`，Spring 用 getter 序列化，列名 `stat_hour` 只在数据库侧。
- **为什么要 CORS？** 前端和后端不同源，跨域请求被浏览器拦，需放行。
- **接口返回的数据从哪来？** 查 MySQL `stat_result` 表，而该表由 Spark 处理结果写入。
