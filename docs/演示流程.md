# 答辩演示流程

> 整条链路：原始日志 → **Kafka 采集** → **Spark 流式处理** → **MySQL + HBase + HDFS 存储** → **后端接口** → **前端看板**
> 全部命令在 **node1** 执行（FinalShell 连 `hadoop@192.168.88.101`，建议开 2 个标签：A 跑命令、B 查结果）。

1. VMware 里开三台虚拟机 **node1 / node2 / node3**
2. FinalShell 连 node1（开 2 个标签）
3. 浏览器准备：前端 `frontend/index.html` + 几个集群 Web UI

```bash

```
- **作用**：按 ZooKeeper → HDFS → YARN → HBase → Kafka → MySQL → 后端 的正确顺序一键启动（幂等，已跑的自动跳过）

## 动态演示（流计算实时落库）

1. **先打开前端** `frontend/index.html`，勾上「自动刷新 3s」——此刻是空的/0
2. 再执行：
```bash
bash demo.sh /home/hadoop/sample-50k.txt 4000 2
```
- **作用**：清空(MySQL/HBase/topic/checkpoint) → 启动 Spark 流式作业 → producer 发送 5 万条日志（约 1 分钟）
- **看到**：**前端柱状图和数字从 0 一节节往上长**，最后时间段数 = 24、图表铺满
- **讲三个点**：
  1. "Kafka 实时采集日志，发送到 topic `gds-log-topic`"
  2. "**Spark Structured Streaming 流式消费 Kafka**，微批聚合每小时每航司成功数"（← 加分项①）
  3. "实时写入 MySQL，前端每 3 秒刷新，秒级可见数据增长"

> 参数 `4000 2` = 每批 4000 条、每 2 秒一批，控制"涨多快"。想更丰富可换 `sample-300k.txt`(32万行,约5分钟)。

## 三存储演示（加分项：HBase + HDFS）

演示"统计结果同时落三种存储"：
```bash
# 先清 MySQL，避免和上一步数据叠加
mysql -uroot -proot -e "TRUNCATE TABLE bigdata_exp4.stat_result;"

# 批处理：一次性把结果写入 MySQL + HBase + HDFS
spark-submit --class com.bigdata.processor.AirlineSuccessProcessor \
  /home/hadoop/processor-fx.jar --mode local --input file:///home/hadoop/sample-50k.txt
```
跑完，**标签 B 当场给评委看三份数据**：
```bash
mysql -uroot -proot -e "SELECT COUNT(*) FROM bigdata_exp4.stat_result;"                # ① MySQL
echo "scan 'stat_result',{LIMIT=>5}" | /export/server/hbase/bin/hbase shell -n         # ② HBase
hdfs dfs -cat /user/hadoop/stat_result_out/part-*.csv | head                            # ③ HDFS
```
- **讲点**："结果同时存进 **MySQL**(供后端查询) + **HBase 列式存储**(加分②) + **HDFS**(加分③，满足'结果存 HDFS'要求)"

## （可选）· YARN 分布式跑 Spark

强化"分布式计算"：
```bash
spark-submit --class com.bigdata.processor.AirlineSuccessProcessor \
  --master yarn --deploy-mode client /home/hadoop/processor-fx.jar \
  --mode local --input file:///home/hadoop/sample-50k.txt
```
→ YARN UI http://192.168.88.101:8088 看到任务 Container 分布在 node1/2/3
→ **Spark 分布式执行的现场证据**

## 出问题的兜底
- 某服务没起：单独 `bash start-all.sh`（幂等，会补起缺的）
- 前端不更新：手动点「刷新」或确认勾了「自动刷新」
- YARN 跑 Spark 不稳：去掉 `--master yarn`，用默认 local 模式照样能演
- 数字想从零重演：直接重跑 `bash demo.sh ...`（它会自动清空）
